海外の配信を見ていると、チャットが速すぎて読めない、全部を翻訳すると重くて止まる、ということがあります。Boxlateは、チャット欄の好きな場所にドラッグで「翻訳ウィンドウ（枠）」を描き、その枠を通ったコメントだけを日本語にして、数秒間表示するブラウザ拡張です。Twitch と YouTube Live で使えます。Chromeウェブストアで公開しています。

![チャット欄に重ねた翻訳ウィンドウで、英語やスペイン語のコメントが日本語になっている](/works/boxlate.png)

## 枠を通ったコメントだけ

チャット全体ではなく、枠に入ったコメントだけを翻訳するので、軽く、止まりません。英語・スペイン語・韓国語などのコメントを、日本語・英語・韓国語・中国語・スペイン語の5つの言語に翻訳できます。Kappa のような配信サイト独特のエモートには、「煽り・皮肉」のように意味を日本語で添えます。

## 枠を描いて、オンにするだけ

翻訳する範囲はドラッグで指定し、位置や大きさはあとから変えられます。翻訳したコメントを表示しておく時間や、翻訳したコメントの読み上げ（TTS）も設定できます。

![枠の指定、翻訳先の言語、ホールド時間、読み上げを設定する画面](/works/boxlate-settings.png)

## 配信者の声にも字幕（実験的機能）

Twitch では、配信者が話した内容を文字に起こして翻訳し、画面の下に字幕として出せます。自分の OpenAI の API キーを使う方式で、費用の目安は1時間あたり数十円ほど、字幕は10〜15秒ほど遅れて表示されます。

![英語で話す配信者の声が、日本語の字幕になって画面の下に出ているイメージ](/works/boxlate-captions.png)

## 仕組み

枠と重なったチャットの要素だけを検知して翻訳するので、チャット全体を監視するより負荷が小さく済みます。翻訳は API キーなしで使える方法を基本にしていて、自分の Google Cloud Translation の API キーを設定することもできます。同時に送る件数の上限や、同じ文の翻訳結果の再利用で、翻訳サービスに負担をかけないようにしています。
